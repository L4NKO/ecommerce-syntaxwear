# 👟 SyntaxWear - Tênis e Sneakers Online

O SyntaxWear é um projeto fictício de interface de e-commerce desenvolvido com HTML5 e CSS3, como parte dos meus estudos no curso DevQuest (Dev em Dobro).

O objetivo foi praticar a estruturação de páginas web, estilização com CSS e criação de layouts responsivos, utilizando Flexbox, CSS Grid e Media Queries.

---

## 🚀 Demonstração

[Acessar o projeto online](https://l4nko.github.io/ecommerce-syntaxwear/)

---

## 💻 Tecnologias Utilizadas

Neste projeto, utilizei as seguintes tecnologias e técnicas de desenvolvimento Front-end:

* **HTML5**: Estruturação do conteúdo e utilização de elementos semânticos.
* **CSS3**: Estilização e organização visual.
* **Flexbox**: alinhamento e distribuição dos elementos.
* **CSS Grid**: organização da seção de produtos.
* **Media Queries**: adaptação do layout para diferentes tamanhos de tela.
* **Variáveis CSS**: organização de cores e fontes.

---

## 🚀 Funcionalidades e Seções do Site

* Cabeçalho com navegação e menu hambúrguer para dispositivos móveis, desenvolvido com CSS.

* Seção principal (Hero) com apresentação da marca.

* Cards de categorias de tênis com efeitos de hover.

* Galeria de produtos em destaque organizada com CSS Grid.

* Rodapé com links de navegação e redes sociais.

* Layout responsivo para desktop e dispositivos móveis.

Observação: o projeto é uma interface demonstrativa, sem sistema de compras ou pagamentos.

  ---

## 🎨 Design e Identidade Visual

O design do SyntaxWear foi construído com base em uma paleta de cores moderna e tipografia limpa, configuradas através de **Variáveis CSS** no arquivo `css/variables.css`:

* **Fonte Principal**: `'Ubuntu', sans-serif` (importada diretamente do Google Fonts para dar um visual moderno e legível).
* **Paleta de Cores**:
  * **Cor Primária**: `#1a1a1a` (Preto profundo para elegância e sofisticação).
  * **Cor Secundária**: `#f5f5f5` (Cinza claro para fundos suaves e contraste confortável).
  * **Cor de Destaque (Accent)**: `#ff6600` (Laranja vibrante para atrair o olhar aos botões importantes e links ativos).

---

## 📁 Estrutura de Pastas do Projeto

Os estilos CSS foram separados em arquivos para facilitar a organização e manutenção:

- `base.css` — Estilos gerais.
- `reset.css` — Redefinição de estilos.
- `variables.css` — Cores, fontes e variáveis.
- `components/` — Estilos do cabeçalho, rodapé, Hero, categorias e produtos.

## 🛠️ Como Executar o Projeto Localmente

Clone o repositório utilizando o Git:

```bash
git clone https://github.com/L4NKO/ecommerce-syntaxwear.git
```

Abra a pasta do projeto no VS Code e execute o arquivo index.html no navegador.

Também é possível utilizar a extensão Live Server.
